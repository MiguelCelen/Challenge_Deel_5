# Het universum van Miguel

Een eigen wereld in three.js: een huisje met een naamkaart, bomen, wolken en vliegende flamingo's. De camera vliegt bij het laden van ver weg naar het huis.

## Wat zit erin
- Huis van geometrieën (muren, dak, deur, ramen, schoorsteen) met kleur en een baksteentextuur
- Witte naamkaart aan de gevel
- Bomen en wolken die met een lus worden geplaatst
- Een flamingo uit een GLB-model, drie keer geplaatst
- Directioneel licht en omgevingslicht
- Animaties: camera met GSAP, drijvende wolken, rondvliegende flamingo's

## Starten
```bash
npm install
npm run dev
```

## Bouwen
```bash
npm run build
```

## Bronnen
De flamingo en de texturen komen uit de voorbeelden van three.js.
